# QuickBooks × AI tools — R2 landing page prototypes

Static HTML prototypes of the R2 landing page from the Figma file
*Competitor-LLM-landing-pages*. Three variants of the "Choose the AI tool you want to connect" section:

| Page | Variant |
|---|---|
| `index.html` | Hub linking the three options |
| `self-id.html` | Option 1 · Self ID (bento box) — slide sideways for more card sets |
| `carousel.html` | Option 2 · Carousel |
| `grid.html` | Option 3 · Highlighted card in a card grid |

Everything is plain HTML/CSS/JS — no build step. Open `index.html` locally or serve the folder with GitHub Pages.

Notes: fonts are substituted (Inter in place of Tally); partner logos are placeholders pending brand approval; `assets/hero.mp4` is the 1:1 MM4 "Prospects evaluating QuickBooks" clip.
